Design Dynamic Array

Design a Dynamic Array (Resizable Array) class, similar to an ArrayList in Java or vector in C++.

Operations

  • Get an element by index
  • Set an element by index
  • PushBack
  • PopBack
  • Resize when full
  • Return size
  • Return capacity

Example

Input:
["Array",1,"pushback",1,"getCapacity"]

Output:
[null,null,1]
