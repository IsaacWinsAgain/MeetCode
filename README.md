# MeetCode

MeetCode is a platform where programmers can challenge each other to live coding battles and improve their problem-solving skills through competition.

## Current Features

- Enter username
- Create room
- Join room
- Generate room codes

## Planned Features

- Real-time multiplayer
- Coding challenges
- Matchmaking
- Leaderboards
- User profiles
- Rating system

## Tech Stack

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Status

Currently in active development.
